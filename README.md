## How to Run the Code

1. Clone the repository:
   ```sh
   git clone https://github.com/YOUR_GITHUB_USERNAME/Data-Structure-in-cpp.git
   ```
2. Navigate to the project directory:
   ```sh
   cd Data-Structure-in-cpp
   ```
3. Compile and run a C++ file (Example: `stack.cpp`):
   ```sh
   g++ C++/stack/stack.cpp -o stack
   ./stack
   ```
4. Compile and run a C file (Example: `Array.c`):
   ```sh
   gcc C/Array.c -o array
   ./array
   ```
